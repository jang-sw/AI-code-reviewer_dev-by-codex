# 자격증명 커밋 방지

비밀번호·Git 토큰·OpenAI API 키는 운영 환경변수 또는 저장소 밖의 비밀 관리 도구에 둔다. 예제 파일에는 `replace-me`처럼 값이 아닌 짧은 안내만 적는다. 실제 값을 이슈·로그·문서·테스트 fixture에 넣지 않는다.

## 검사 실행

Python 3.10 이상 표준 라이브러리와 Git만 사용하며 외부 전송은 하지 않는다. 저장소 루트에서 실행한다.

```powershell
# Git에 등록된 파일의 현재 작업 내용을 검사한다.
python scripts/check-secrets.py --tracked

# 커밋 직전: 변경된 파일뿐 아니라 Git index 전체를 검사한다.
python scripts/check-secrets.py --staged

# 임시 Git 저장소 기반 회귀 테스트
python -m unittest discover -s scripts/tests -p 'test_*.py'
```

CI는 checkout 직후 `--tracked`와 회귀 테스트를 실행한다. 커밋할 내용을 확인하려면 `--staged`를 사용한다. 비밀이 들어 있는 파일을 `git add`한 후 작업 파일만 정리해도 index에는 원래 값이 남으므로 `--staged`가 계속 차단한다. 작업 파일이 삭제되어도 index에 남아 있으면 검사 대상이다.

미추적·ignored 파일은 열거나 검사하지 않는다. 실제 로컬 `.env`도 Git에 등록되어 있지 않으면 읽지 않는다. Git이 추적하는 `.env` 및 `.env.*` 이름은 내용과 무관하게 차단하고 값을 읽지 않는다. `.env.example` 이름은 허용하지만 그 내용의 키·개인 키 검사는 그대로 적용한다.

## 탐지 및 출력

- OpenAI 키 접두어 `sk-`, `sk-proj-`, `sk-svcacct-` 뒤에 영문·숫자·밑줄·하이픈으로 구성된 32자 이상의 값.
- PEM/OpenSSH 등 `PRIVATE KEY` 헤더 및 PGP 개인 키 헤더.
- 위의 금지된 환경 파일 이름.

출력은 JSON으로 이스케이프한 경로, 줄 번호, 분류만 포함한다. 원문·매칭 값·문맥·Git 오류 내용은 출력하지 않는다. 파일 전체 오류의 줄 번호는 `0`이다. 종료 코드는 `0`(검사 완료·발견 없음), `1`(차단 항목 발견), `2`(읽기 오류·지원하지 않는 입력 등으로 검사 미완료)이며 `2`를 통과로 취급하면 안 된다.

파일당 16 MiB를 넘으면 미완료로 실패한다. 심볼릭 링크·하위 모듈·병합 충돌 index는 검사 대상 전체를 안전하게 확인할 수 없어 실패한다. 작업 파일 경로의 각 구성 요소를 `lstat`으로 확인하고 심볼릭 링크 및 Windows junction을 포함한 모든 reparse point를 거부한다. 이 검사는 Python 3.12의 `Path.is_junction`에 의존하지 않으며 Windows에서 reparse 속성을 확인할 수 없으면 미완료로 실패한다. 압축·암호화·인코딩된 비밀, 다른 공급자 토큰, 임의 비밀번호, Git 과거 이력은 이 제한적인 ASCII 패턴 검사만으로 탐지할 수 없다. 통과는 비밀이 전혀 없다는 보장이 아니다.

## 발견 시

실제 자격증명이 Git index·커밋·공유 로그에 들어갔다면 해당 서비스에서 폐기·재발급하고 노출 범위를 확인한다. 먼저 소스의 값을 환경변수 참조로 바꾼 후 정리된 파일을 다시 stage하여 `--staged`를 재실행한다. 실제 환경 파일은 추적을 해제하고 ignore 규칙을 확인한다. 이미 공개된 값은 파일을 지우는 것만으로 안전해지지 않는다. 원격 이력 재작성이나 운영 자격증명 교체는 해당 운영 권한·승인 절차에 따른다.
